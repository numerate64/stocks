# Numerate Markets — archived static build

This repository contains the source for the former public GitHub Pages stock dashboard. Its Pages deployment and scheduled snapshot publisher were retired on 2026-11-19; the static app is no longer served from this repository.

The former version stored each visitor's watchlist in browser local storage. That data was not part of this repository. The current stock watchlist is maintained separately by the private dashboard service and is stored in its local SQLite database.

The files here are retained as a source archive. They are not used by the current dashboard.
